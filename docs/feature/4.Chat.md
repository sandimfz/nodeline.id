## 3. WebSocket Gateway ✅

**Client → Server:**
- [x] `conversation:join { conversationId }` — validasi ownership sebelum join room `conv:{id}`
- [x] `message:send { conversationId, content, tempId }` — simpan ke DB, broadcast, ack
- [x] `typing:start / typing:stop { conversationId }` — broadcast typing status
- [x] `conversation:leave { conversationId }` — leave room

**Server → Client:**
- [x] `message:new { message }` — broadcast ke room setelah save DB
- [x] `message:ack { tempId, message }` — konfirmasi ke pengirim (reconcile optimistic)
- [x] `typing:update { conversationId, userId, isTyping }`
- [x] `conversation:closed { conversationId }`
- [x] `error { code, message }` — rate limit, access denied, dll

## 4. Keamanan ✅

- [x] **Autentikasi handshake**: one-time ticket (random 32-byte base64url), 30 detik expiry, sekali pakai
- [x] **Re-validasi per event**: setiap `message:send` / `conversation:join` cek ownership ke DB
- [x] **Force-disconnect on logout**: `forceDisconnectUser()` cari semua socket userId di registry
- [x] **Anti-IDOR**: cross-check `conversation.userId === socket.data.userId` atau role `god`
- [x] **senderRole dari server** (socket.data), bukan payload client
- [x] **Rate limit**: 10 pesan / 10 detik per socket, cleanup on disconnect
- [x] **Validasi content**: tidak kosong, ≤4000 karakter
- [x] **CORS origin whitelist**: dari env `CORS_ORIGINS`
- [x] **Payload size limit**: `maxHttpBufferSize: 1MB`
- [x] **UUID untuk semua ID**

## 7. Alur Data

### User Kirim Pesan
```
User → chat-client.tsx → useSendMessage (optimistic update)
     → socket "message:send" → ChatGateway.handleMessage()
     → saveMessage() ke DB
     → broadcast "message:new" ke room (termasuk user sendiri)
     → socket "message:ack" → onSuccess reconcile optimistic
```

### Admin Balas Pesan
```
Admin → ChatConversationDetailPage → api.post("/chat/conversations/:id/messages")
     → ChatController.sendMessage()
     → saveMessage() ke DB
     → chatGateway.broadcastNewMessage() → socket "message:new" ke room
     → User terima realtime (tanpa refresh)
```

## 8. Edge Cases Handled

- [x] **Double bubble**: dedup by message.id di socket handler + onSuccess
- [x] **Unread badge persist**: `markAsRead` dipanggil saat buka chat, invalidate `unreadCount`
- [x] **Admin 401**: pakai axios instance, bukan fetch() — token otomatis terattach
- [x] **Rate limit**: per-socket, cleanup on disconnect
- [x] **Multiple tabs**: 1 userId → banyak socketId, semua dapat broadcast

## 9. Performance Notes

- Unread count polling: 15 detik (sidebar)
- Messages cursor pagination: limit 50 per page
- StaleTime: 30 detik untuk messages & conversations
- Ticket expiry: 30 detik (one-time, langsung dihapus)
- Rate limit: 10 messages / 10 detik per socket
- Socket registry: in-memory (single instance), Redis untuk multi-instance nanti
