## Ringkasan

Halaman marketplace publik menampilkan katalog produk dari API dengan **server-side prefetch** — tidak ada loading spinner, data sudah tersedia saat halaman di-render.

## Arsitektur

### Prefetch (Server Component)

```
Server Component (page.tsx)
  ↓
fetchProductsServer() — fetch langsung ke NestJS (API_BASE_URL)
  ↓
Data produk dikirim sebagai props ke Client Component
  ↓
Client Component (card-product.tsx) — render langsung, tanpa loading/error state
```

**Kenapa prefetch?**
-  Tidak ada flash loading/empty state
-  Data sudah siap saat HTML pertama dikirim
-  Client cukup render — tidak perlu fetch tambahan

### BFF Endpoints

Semua request publik:

| Endpoint | Method | Fungsi |
|---|---|---|
| `/api/v1/bff/products` | GET | Katalog produk (server-side) |

### BFF Endpoints

Semua request publik:

| Endpoint | Method | Fungsi |
|---|---|---|
| `/api/v1/bff/products` | GET | Katalog produk (server-side) |
| `/api/v1/bff/products/:id` | GET | Detail produk |
