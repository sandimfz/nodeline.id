# Fitur Auth — Implementasi Frontend

**Status:  Selesai**  
**Referensi backend:** `POST /auth/register`, `POST /auth/login`, `POST /auth/refresh`, `POST /auth/logout`, `GET /auth/me`

---

## Arsitektur

Pola **BFF (Backend-for-Frontend)** via Next.js Route Handler:

```
Browser → /api/v1/bff/auth/* → BFF Route Handler (app/api/v1/bff/[...path]/route.ts) → Nest API (port 3000)
```

**Cookie management:**
- `nl_session` (httpOnly, path=/) — access token JWT, dikelola BFF
- `nl_refresh` (httpOnly, path=/api/v1/bff) — refresh token opaque, dari Nest

**Route protection:**
- `proxy.ts` (Next.js 16) — guard route berbasis cookie `nl_session`
- Protected: `/dashboard`, `/me`, `/orders`, `/checkout`, `/admin`
- Auto-redirect ke `/auth/login` jika belum login

## 10. Update Profile (`PATCH /auth/me`) 

### Frontend Layer

| File | Fungsi |
|---|---|
| `features/auth/schema.ts` | `updateProfileSchema` — Zod: name min 2, max 50 karakter |
| `features/auth/api.ts` | `updateProfile(data)` — validasi + kirim PATCH via BFF |
| `features/auth/hooks.ts` | `useUpdateProfile()` — mutation, update zustand + query cache |
| `app/(app)/dashboard/profile/page.tsx` | Halaman profil dengan form controlled via ref |

### Security — Dual Layer Validation

```
User klik Simpan
  ↓
1. CLIENT (api.ts): cek RAW input — ada field selain 'name'? → error "Parameter 'email' tidak diizinkan"
2. CLIENT (api.ts): Zod validasi name → error "Nama minimal 2 karakter"
3. BFF: forward ke Nest dengan JWT dari session cookie (no IDOR)
4. SERVER (Nest): ValidationPipe whitelist + forbidNonWhitelisted → error kalau ada field asing
5. SERVER (Nest): update name di database
```

### Allowed Fields

Hanya `name` yang bisa diubah. Field lain (`email`, `role`, dll) ditolak baik di client maupun server.

### Error Messages

| Skenario | Pesan |
|---|---|
| Name kosong | "Nama tidak boleh kosong" |
| Name < 2 karakter | "Nama minimal 2 karakter" |
| Name > 50 karakter | "Nama maksimal 50 karakter" |
| Field asing (email) | "Parameter 'email' tidak diizinkan" |
| Field asing (role) | "Parameter 'role' tidak diizinkan" |

### UI State

| State | Tampilan |
|---|---|
| Loading | Button "Menyimpan..." + disabled |
| Success | Toast "Profil berhasil diperbarui" + zustand store diupdate |
| Error | Inline error text merah + toast error |
| Dirty | Button "Simpan perubahan" enabled |
