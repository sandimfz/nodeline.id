# Fitur Auth — Admin Panel

**Status: ✅ Selesai**  
**Referensi backend:** `POST /auth/login`, `POST /auth/refresh`, `POST /auth/logout`, `GET /auth/me`

---

## Arsitektur

Admin panel menggunakan pola **Vite Proxy BFF**:

```
Admin Browser → /api/auth/* → Vite dev server proxy → Nest API (port 3000)
```

**Token management:**
- `accessToken` — disimpan di **localStorage** (beda dengan client user yang httpOnly cookie)
- `refreshToken` — disimpan di **localStorage**
- Setiap request API menyertakan `Authorization: Bearer <token>` header
- Axios interceptor otomatis handle 401 → refresh → retry

## 8. Alur Login

```
1. Admin input email + password
2. Zod validasi client-side
3. POST /api/auth/login → proxy → Nest
4. Nest validasi → return { accessToken, refreshToken, user }
5. Simpan token + user ke localStorage + zustand
6. Redirect ke /dashboard
7. useMe() fetch /api/auth/me untuk verifikasi + update data
```
